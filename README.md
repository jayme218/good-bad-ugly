# The Good, The Bad, and The Ugly

Three pieces of news a day. Then close the tab.

See [Publishing an edition](docs/PUBLISHING.md) for the daily content and release checklist.

See [Free automatic publishing](docs/AUTOMATION.md) for daily collection, Pages setup, and editing a published draft.

## Owner editing

Open the [edition editor](https://jayme218.github.io/good-bad-ugly/#/editor) to correct stories with a live preview. Copy the prepared correction and publish it through the owner-only GitHub workflow. See [publishing steps](docs/PUBLISHING.md).

## Develop

```bash
npm install
npm run dev
```

## Build
